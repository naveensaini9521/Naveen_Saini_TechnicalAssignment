How import works

  • All-or-nothing — if any row is invalid, no products are created.
  • Existing product codes are rejected (case-insensitive).
  • Negative prices or stock, invalid status, or non-numeric values cause the whole file to be rejected.
  • Every imported product automatically gets an Opening stock movement.
  • Errors are reported per row with row numbers, so you can fix and retry.
